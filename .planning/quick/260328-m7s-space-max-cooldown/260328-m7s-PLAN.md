Переписать тело UpdateNode по следующей логике:

1. Если `gun.Config == null` — выйти.
2. Если `gun.IsReloading` — тикать таймер: `gun.ReloadTimer -= deltaTime`. Если `gun.ReloadTimer <= 0f` — сбросить `gun.ReloadTimer = 0f` и `gun.CurrentShoots = 0`. После этого не стрелять в этом фрейме (выйти или продолжить — счётчик обнулён, Shooting будет обработан в следующем нажатии).
3. Если НЕ перезаряжается и `gun.Shooting` и `gun.CurrentShoots < gun.Config.MaxShoots`:
   - `gun.CurrentShoots++`
   - `gun.OnShooting?.Invoke(gun)`
   - Если после инкремента `gun.CurrentShoots >= gun.Config.MaxShoots`: запустить кулдаун `gun.ReloadTimer = gun.Config.ReloadDurationSec`
4. Сбросить `gun.Shooting = false`.

Итоговая логика (псевдокод):
```
if config == null → return
if IsReloading:
    ReloadTimer -= deltaTime
    if ReloadTimer <= 0: ReloadTimer = 0; CurrentShoots = 0
    Shooting = false
    return
if Shooting and CurrentShoots < MaxShoots:
    CurrentShoots++
    OnShooting?.Invoke(gun)
    if CurrentShoots >= MaxShoots:
        ReloadTimer = Config.ReloadDurationSec
Shooting = false
```

Использовать фигурные скобки для всех блоков (стиль K&R, как в окружающем коде).
