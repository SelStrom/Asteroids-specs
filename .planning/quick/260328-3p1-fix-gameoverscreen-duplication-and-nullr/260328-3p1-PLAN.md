<task type="auto">
  <name>Task 2: Назначить UserGunData в GameData.Ship.Gun в Phase3Setup</name>
  <files>Assets/Editor/Phase3Setup.cs</files>
  <action>
Причина NullReferenceException: `Phase3Setup.CreateConfigAssets()` создаёт `UserGunData.asset` и `GameData.asset` по отдельности, но не назначает `UserGunData` в `gameData.Ship.Gun`. В результате `configs.Ship.Gun == null`, `ShipModel.Setup()` создаёт `new GunComponent(null)`, и `GunSystem.UpdateNode()` падает на `gun.Config.MaxShoots`.

В методе `CreateConfigAssets()`, после создания `userGun` и `gameData`, добавить назначение `Ship.Gun` через `SerializedObject`. Вставить перед вызовом `CreateOrReplaceAsset(gameData, ...)`:

```csharp
gameData.Ship = new GameData.ShipData
{
    ThrustUnitsPerSecond = 6f,
    MaxSpeed = 15f
    // Prefab, MainSprite, ThrustSprite — назначить через Inspector
};
```

Это поле `struct`, поэтому `GunData` (ScriptableObject-ссылка) внутри struct нельзя назначить через инициализатор до сохранения asset. После `CreateOrReplaceAsset(gameData, ...)` загрузить оба asset и назначить через `SerializedObject`:

```csharp
// Назначить userGun в gameData.Ship.Gun
var savedGameData = AssetDatabase.LoadAssetAtPath<GameData>("Assets/Media/configs/GameData.asset");
var savedUserGun = AssetDatabase.LoadAssetAtPath<GunData>("Assets/Media/configs/UserGunData.asset");
if (savedGameData != null && savedUserGun != null)
{
    var serializedGameData = new SerializedObject(savedGameData);
    serializedGameData.FindProperty("Ship.Gun").objectReferenceValue = savedUserGun;
    serializedGameData.ApplyModifiedProperties();
}
```

ВАЖНО: `serializedGameData.FindProperty("Ship.Gun")` — путь к полю в struct через точку. Проверить точный путь — Unity может использовать `"Ship"` → FindProperty → затем `FindPropertyRelative("Gun")`. Безопасный вариант:

```csharp
var serializedGameData = new SerializedObject(savedGameData);
var shipProp = serializedGameData.FindProperty("Ship");
if (shipProp != null)
{
    var gunProp = shipProp.FindPropertyRelative("Gun");
    if (gunProp != null)
    {
        gunProp.objectReferenceValue = savedUserGun;
    }
}
serializedGameData.ApplyModifiedProperties();
```

Добавить этот блок в конце `CreateConfigAssets()`, после строки `UnityEngine.Debug.Log("[Phase3Setup] Config assets created.");`.
  </action>
