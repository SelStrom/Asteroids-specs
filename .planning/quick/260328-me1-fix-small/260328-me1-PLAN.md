## Анализ корневых причин

### Баг 1: Пуля без спрайта

**Причина**: `BulletVisual.OnConnected()` биндит только `Position`. У `BulletViewModel` нет поля `Sprite`.
В `bullet.prefab` SpriteRenderer пуст (`m_Sprite: {fileID: 0}`). Нигде не устанавливается спрайт пули.

**Спрайт пули**: fileID=11, guid=`cf467e92e508b5878eb24c5a126421e0` (файл `asteroids.png`), имя `bullet`.

**Паттерн решения** (идентичен AsteroidVisual):
1. Добавить `Sprite BulletSprite` в `GameData.BulletData`
2. Добавить `ReactiveValue<Sprite> Sprite = new()` в `BulletViewModel`
3. В `BulletVisual.OnConnected()` добавить биндинг `ViewModel.Sprite.Connect(val => { if (_spriteRenderer != null && val != null) { _spriteRenderer.sprite = val; } })`
4. Добавить `[SerializeField] private SpriteRenderer _spriteRenderer;` + Awake guard в `BulletVisual`
5. В `EntitiesCatalog.CreateBullet()` установить `vm.Sprite.Value = _configs.Bullet.BulletSprite`
6. В `GameData.asset` добавить ссылку на bullet спрайт
7. В `Phase4Setup.UpdateGameData()` добавить автоматическое назначение `BulletSprite`

### Баг 2: Small астероиды не видны

**Анализ**: Конфиги корректны — `AsteroidSmallData.asset` имеет `Prefab` и `SpriteVariants` (medium-спрайты, как решено в STATE.md). `GameData.AsteroidSmall` назначен.

**Вероятная причина**: `AsteroidVisual._spriteRenderer` — поле с `[SerializeField]`. В prefab оно `{fileID: 0}` (не назначено). При первом `Instantiate` — `Awake()` вызывает `GetComponent<SpriteRenderer>()` и заполняет поле. Но если по какой-то причине (порядок инициализации, активация через пул) `Awake()` не находит компонент или `_spriteRenderer` сброшен — спрайт не устанавливается.

**Защитное исправление**: В `AsteroidVisual.OnConnected()` добавить fallback: `if (_spriteRenderer == null) { _spriteRenderer = GetComponent<SpriteRenderer>(); }` перед биндингом.

**Дополнительно**: В `Phase4Setup.CreateOrUpdateAsteroidPrefab()` после `AddComponent<AsteroidVisual>()` назначить `_spriteRenderer` через SerializedObject — чтобы prefab содержал правильную ссылку до рантайма.
