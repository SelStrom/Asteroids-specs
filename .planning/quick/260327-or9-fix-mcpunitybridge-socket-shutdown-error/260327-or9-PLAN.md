# Quick Task 260327-or9: Fix McpUnityBridge socket-shutdown error

**Problem:** `list_scenes` (and any MCP tool) throws "Unable to write data to the transport connection: The socket has been shut down" because the socket closes between `GetContext()` (background thread) and the `delayCall` handler (main thread).

**Root causes:**
1. Domain reload triggers `StopServer()` → `_listener.Stop()` while a request is in flight
2. Client disconnects before `delayCall` fires

**Fix:**
1. Check `_running` in delayCall lambda before calling `HandleRequest` — abort gracefully if server stopped
2. Wrap `SendJsonRaw` writes in try-catch for `SocketException`, `ObjectDisposedException`, `IOException` — swallow silently (client disconnected)
