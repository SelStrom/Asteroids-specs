**Структура класса** (per D-06, D-07, D-08, D-09):
- Атрибут `[InitializeOnLoad]` на класс `public static class McpUnityBridge`
- Поля: `private static HttpListener _listener; private static Thread _listenerThread; private static volatile bool _running;`
- Поля для компиляции: `private static readonly List<CompilerMessage> _compilationMessages = new List<CompilerMessage>(); private static volatile bool _compiling;`
- Статический конструктор: подписки + `SubscribeCompilation()` + `StartServer()`
- `StartServer()`: создаёт HttpListener на `"http://localhost:8765/"`, запускает Thread с `IsBackground = true`
- `ListenLoop()`: цикл `while (_running)` с `_listener.GetContext()` и `EditorApplication.delayCall += () => HandleRequest(context)`
- `StopServer()`: `_running = false`, `_listener?.Stop()`, `_listenerThread?.Join(1000)`
- Подписки на shutdown: `AssemblyReloadEvents.beforeAssemblyReload += OnBeforeAssemblyReload` и `EditorApplication.quitting += OnEditorQuitting`

**SubscribeCompilation():**
```csharp
private static void SubscribeCompilation()
{
    CompilationPipeline.compilationStarted += _ => {
        _compilationMessages.Clear();
        _compiling = true;
    };
    CompilationPipeline.assemblyCompilationFinished += (assemblyName, messages) => {
        _compilationMessages.AddRange(messages);
    };
    CompilationPipeline.compilationFinished += _ => {
        _compiling = false;
    };
}
```

**HandleRequest(HttpListenerContext context)** — dispatch по `context.Request.Url.LocalPath`:
- `"/compile"` → `HandleCompile(context)`
- `"/play"` → `HandlePlay(context)`
- `"/stop"` → `HandleStop(context)`
- `"/list_scenes"` → `HandleListScenes(context)`
- `"/open_scene"` → читает body JSON `{ "path": "..." }`, вызывает `HandleOpenScene(context, path)`
- `"/import_asset"` → читает body JSON `{ "path": "..." }`, вызывает `HandleImportAsset(context, path)`
- Неизвестный path → 404 с `{ "success": false, "message": "Unknown endpoint" }`

**HandleCompile(HttpListenerContext context):**
```csharp
AssetDatabase.Refresh();
var errors = _compilationMessages.FindAll(m => m.type == CompilerMessageType.Error);
var warnings = _compilationMessages.FindAll(m => m.type == CompilerMessageType.Warning);
if (errors.Count > 0)
{
    var errorList = errors.ConvertAll(e => new {
        file = e.file, line = e.line, column = e.column,
        message = e.message, severity = "error"
    });
    SendJson(context, new { success = false, errorCount = errors.Count, errors = errorList });
}
else
{
    SendJson(context, new { success = true, message = $"Compilation successful. {warnings.Count} warnings." });
}
```

**HandlePlay / HandleStop:**
```csharp
private static void HandlePlay(HttpListenerContext context)
{
    EditorApplication.isPlaying = true;
    SendJson(context, new { success = true, message = "Play Mode started" });
}
private static void HandleStop(HttpListenerContext context)
{
    EditorApplication.isPlaying = false;
    SendJson(context, new { success = true, message = "Play Mode stopped" });
}
```

**HandleListScenes:**
```csharp
private static void HandleListScenes(HttpListenerContext context)
{
    var guids = AssetDatabase.FindAssets("t:Scene");
    var scenes = new List<string>();
    foreach (var guid in guids)
    {
        scenes.Add(AssetDatabase.GUIDToAssetPath(guid));
    }
    SendJson(context, new { success = true, scenes = scenes.ToArray() });
}
```

**HandleOpenScene(HttpListenerContext context, string path):**
```csharp
private static void HandleOpenScene(HttpListenerContext context, string path)
{
    try
    {
        EditorSceneManager.OpenScene(path, OpenSceneMode.Single);
        SendJson(context, new { success = true, message = $"Opened scene: {path}" });
    }
    catch (Exception ex)
    {
        SendJson(context, new { success = false, message = ex.Message });
    }
}
```

**HandleImportAsset(HttpListenerContext context, string path):**
```csharp
private static void HandleImportAsset(HttpListenerContext context, string path)
{
    AssetDatabase.ImportAsset(path, ImportAssetOptions.ForceUpdate);
    SendJson(context, new { success = true, message = $"Imported asset: {path}" });
}
```

**SendJson(HttpListenerContext context, object data):**
```csharp
private static void SendJson(HttpListenerContext context, object data)
{
    var json = UnityEngine.JsonUtility.ToJson(data);
    // Используем простой JSON т.к. JsonUtility ограничен — для сложных объектов строим вручную
    // Для compile errors нужна ручная сериализация или System.Text.Json
    var bytes = Encoding.UTF8.GetBytes(json);
    context.Response.ContentType = "application/json";
    context.Response.ContentLength64 = bytes.Length;
    context.Response.OutputStream.Write(bytes, 0, bytes.Length);
    context.Response.OutputStream.Close();
}
```

ВАЖНО: `UnityEngine.JsonUtility.ToJson` не поддерживает анонимные типы и массивы верхнего уровня. Вместо этого используй ручную JSON-сериализацию для всех ответов bridge. Для `HandleCompile` со списком ошибок построй JSON строкой через `StringBuilder`. Для простых ответов (`{ "success": true, "message": "..." }`) можно использовать `$"{{\"success\":{success},\"message\":\"{msg}\"}}"`.
