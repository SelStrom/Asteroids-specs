**Шаг 1: Убедиться что Unity Editor открыт с этим проектом**

В Unity Console не должно быть ошибок компиляции. В Console должно быть сообщение:
```
[McpUnityBridge] Запущен на localhost:8765
```

Если ошибки компиляции есть — сообщи о них (файл + строка + текст ошибки).

**Шаг 2: Проверить регистрацию в Claude Code**

```bash
claude mcp list
```

Ожидаемый вывод содержит `mcp-unity`.

**Шаг 3: Проверить tool `list_scenes`** (самый простой, нет параметров)

В новом чате с Claude Code написать:
```
Use the list_scenes MCP tool to list Unity scenes.
```

Ожидаемый ответ содержит `Assets/Scenes/Main.unity`.

**Шаг 4: Проверить tool `compile`**

```
Use the compile MCP tool to compile Unity scripts.
```

Ожидаемый ответ: `{ "success": true, "message": "Compilation successful. 0 errors." }`

**Шаг 5: Проверить tools `play` и `stop`**

```
Use the play MCP tool to enter Play Mode.
```
Unity должен войти в Play Mode (синяя полоска вверху Editor).

```
Use the stop MCP tool to stop Play Mode.
```
Unity должен выйти из Play Mode.

**Шаг 6: Проверить tool `open_scene`**

```
Use the open_scene MCP tool with path "Assets/Scenes/Main.unity".
```

Ожидаемый ответ: `{ "success": true, "message": "Opened scene: Assets/Scenes/Main.unity" }`

**Шаг 7: Проверить tool `import_asset`**

```
Use the import_asset MCP tool with path "Assets/Scenes/Main.unity".
```

Ожидаемый ответ: `{ "success": true, "message": "Imported asset: Assets/Scenes/Main.unity" }`
