- UGS Auth: `"Unity.Services.Authentication"`
- UGS Leaderboards: `"Unity.Services.Leaderboards"`

```json
"com.shtl.mcp-unity": "file:../Packages/com.shtl.mcp-unity"
```
НЕТ — embedded-пакеты Unity распознаются автоматически по наличию директории `Packages/{package-name}/package.json`. Запись в manifest.json НЕ нужна.
