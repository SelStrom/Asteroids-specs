  <action>
Открыть файл ProjectSettings/EditorBuildSettings.asset и изменить:

ДО:
```
  m_Scenes: []
```

ПОСЛЕ:
```
  m_Scenes:
  - enabled: 1
    path: Assets/Scenes/Main.unity
    guid: [guid из .meta файла сцены]
```

Для получения правильного GUID выполнить:
```bash
grep "guid:" /Users/selstrom/work/projects/asteroids-specs/Assets/Scenes/Main.unity.meta | head -1
```

Подставить найденный GUID в поле `guid`.

ВАЖНО: Это ручное редактирование YAML-файла Unity. Альтернатива (и предпочтительная): если Unity Editor открыт, использовать MCP tool `unity_editor_menu` для открытия `File/Build Settings` и добавления сцены через UI — но по D-02 нет PhaseSetup, поэтому допустимо прямое редактирование .asset файла.

Структура после редактирования (полный файл):
```yaml
%YAML 1.1
%TAG !u! tag:unity3d.com,2011:
--- !u!1045 &1
EditorBuildSettings:
  m_ObjectHideFlags: 0
  serializedVersion: 2
  m_Scenes:
  - enabled: 1
    path: Assets/Scenes/Main.unity
    guid: {GUID из Main.unity.meta}
  m_configObjects: {}
```

  <how-to-verify>
Выполнить шаги в Unity Editor:

**Шаг 1 — Переключить платформу на WebGL:**
1. Открыть `File → Build Settings` (Ctrl+Shift+B / Cmd+Shift+B)
2. В списке платформ выбрать `WebGL`
3. Нажать кнопку `Switch Platform` (если она активна — значит платформа ещё не WebGL)
4. Дождаться завершения переключения (1-5 минут, Unity перекомпилирует скрипты)
5. Убедиться: кнопка внизу теперь `Build` (не `Switch Platform`)

**Шаг 2 — Проверить сцену в списке:**
- В разделе `Scenes In Build` должна быть `Scenes/Main` с галочкой
- Если не появилась: нажать `Add Open Scenes` (убедиться что Main.unity открыта)

**Шаг 3 — Выполнить сборку:**
1. Нажать кнопку `Build`
2. В диалоге выбора папки: перейти в корень проекта (`/Users/selstrom/work/projects/asteroids-specs/`)
3. Создать папку `Build` → внутри неё папку `WebGL`
4. Выбрать папку `WebGL` и нажать `Select Folder` (или аналог на macOS)
5. Дождаться завершения (5-30 минут в зависимости от ПК)

**Признаки успешной сборки:**
- В Unity Console нет ошибок (предупреждения допустимы)
- В папке `Build/WebGL/` появились файлы: `index.html`, `Build/Asteroids.loader.js`, `Build/Asteroids.framework.js`, `Build/Asteroids.wasm`, `Build/Asteroids.data`, папка `TemplateData/`

**Признаки проблем:**
- В Build появился `.exe` → платформа не была переключена на WebGL
- Пустой экран в браузере → сцена не была в Build Settings (проверить Задачу 1)
