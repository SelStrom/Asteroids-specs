**Location:** `Assets/Scripts/Application/EntitiesCatalog.cs` — `CreateUfoSmall()` (строки 211–246)

**Fix:** Добавить `model.MoveTo.Speed = speed;` после `model.Move.Speed.Value = speed;` в `CreateUfoSmall()`

